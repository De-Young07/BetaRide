# BetaRide Web Platform

The official responsive web platform for **BetaRide** — Ilorin's fair-negotiation transit platform ("Move More. Pay Less.").

---

## 🌟 What This Platform Includes

1. **Brand Identity & Local Showcase**:
   - Official brand styling (BetaRide Gold `#F5B301` and Navy Blue `#0D2342`).
   - Authentic imagery from flyers showcasing Ilorin landmarks (Post Office roundabout, Innovation Hub, Tanke).
2. **Interactive "Set Your Price" Fare Estimator**:
   - Live interactive simulator for the **Offa Garage Pilot Corridor**.
   - Select destination (Tanke, Gerin Alimi, Innovation Hub, Post Office, Tipper Garage).
   - Switch between Keke Napep, Motorcycle, and Car drops.
   - Adjust price slider and simulate real-time driver broadcasting and acceptance.
3. **Seamless Unified Auth (Login / Sign Up / Driver Partner Application)**:
   - **Passenger Sign In**: Phone number and PIN/password.
   - **Passenger Sign Up**: Full name, phone, email, and preferred area in Ilorin.
   - **Driver Partner Registration**: Vehicle class (Keke/Bike/Car), plate number, NIN, home park, and guarantor details.
   - Instant local session persistence (updates navigation bar with user profile).
4. **Why BetaRide**:
   - Tackles long wait times in the sun, student luggage hassles, and driver reliability.
5. **Keke & Bike Driver Section**:
   - Pre-funded wallet model explanation (100% cash collection by driver, low commission).
   - Transport union alignment details.
   - 3-step physical verification roadmap at Offa Garage.
6. **Safety & In-App Distress Protocols**:
   - NIN verification, real-time trip monitoring, and SOS response desk.

## 🚀 How to Run Locally

### Option 1: Open Directly in Any Browser
Simply double-click or drag **`index.html`** into Google Chrome, Microsoft Edge, Safari, or Brave. Zero install required!

### Option 2: Run with Node.js
From the project root:
```bash
cd web
node server.js
```
Then visit: **`http://localhost:3000`**

### Option 3: Instant 1-Click Deployment
This web application is static and zero-dependency:
- **Netlify**: Drag and drop the `web/` folder onto [app.netlify.com/drop](https://app.netlify.com/drop).
- **Vercel**: Run `vercel` in the `web` directory.
- **GitHub Pages**: Push to a repository and enable GitHub Pages on root or `/web`.
