# BetaRide design system

The booking surface leads. Deep navy signals trust and structure; signal gold is reserved for the primary ride action and live status; warm neutrals support readability in daylight.

- Body and control type: Plus Jakarta Sans, minimum 16px body size.
- All controls have visible labels, 44px minimum targets and a visible focus ring.
- Booking fields never sit on a photograph. Photography is an adjacent, verified asset only.
- Use semantic CSS tokens from `styles.css`; do not add raw colors to components.
- Support `prefers-reduced-motion`, keyboard use, status announcements and 4.5:1 text contrast.
